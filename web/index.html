All-For-One Cross-Platform CLI & OS Integration

Use space_guard_agent.py across macOS, Windows, Linux, and Chromebooks (Crostini Linux) to automate space thresholds and cloud verification.

macOS (iCloud brctl + Google Drive Mount)
# Check disk & cloud mounts for 74 GB Bootcamp goal
python3 space_guard_agent.py status --target-gb 74

# Verify SHA-256 & offload file to Google Drive
python3 space_guard_agent.py offload \
  --file ~/Downloads/large_archive.zip \
  --provider gdrive

# Native macOS iCloud Drive eviction (keeps in iCloud)
brctl evict ~/Library/Mobile\ Documents/com~apple~CloudDocs/big.mov
Windows / Linux / Chromebook (ChromeOS)
# Chromebook (Crostini Linux) Google Drive Vault path:
# /mnt/chromeos/GoogleDrive/MyDrive/CloudSpaceGuard_Vault

# Windows PowerShell OneDrive / iCloud Pin Eviction:
attrib +U -P "C:\Users\You\OneDrive\large_video.mp4"

# Universal 3rd-Party Cloud (S3 / R2 / Backblaze B2 via rclone):
rclone copy --checksum ./archive.tar.zst r2:my-vault/
